## PART 1: TRUE FULLSCREEN FOCUS MODE

When focus mode activates (START pressed), enter native browser fullscreen:

```js
const enterFocus = () => {
  document.documentElement.requestFullscreen?.()
  setRunning(true)
  setFocusActive(true)
}

const exitFocus = () => {
  document.exitFullscreen?.()
  setRunning(false)
  setFocusActive(false)
}

// Sync state if user presses Escape natively
useEffect(() => {
  const handler = () => {
    if (!document.fullscreenElement) setFocusActive(false)
  }
  document.addEventListener('fullscreenchange', handler)
  return () => document.removeEventListener('fullscreenchange', handler)
}, [])
```

When focusActive === true, the timer component renders as:
  position: fixed, inset: 0, z-index: 9999
  background: #050810 (near-black, deeper than current)
  display: flex, flex-direction: column
  width: 100vw, height: 100vh
  overflow: hidden

When focusActive === false, render the compact panel view as before
(inside the bat-board layout).

The START button now says "ENTER FOCUS" and calls enterFocus().
In fullscreen, a corner button "EXIT FOCUS" (top-right) calls exitFocus()
but does NOT stop the timer — timer keeps running.
  Style: position absolute, top 24px, right 24px
  Text: "✕ EXIT FOCUS", font-size 11px, color #475569, letter-spacing 1px
  Hover: color #FFD700
  No border, no background — ghost button

Also: pressing Escape should NOT stop timer, only exit fullscreen.
Exiting fullscreen keeps focusActive=true but collapses back to panel.
